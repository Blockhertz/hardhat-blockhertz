# Contributing to hardhat-blockhertz

## Getting started

```bash
git clone https://github.com/Blockhertz/hardhat-blockhertz
cd hardhat-blockhertz
pnpm install
pnpm build
pnpm test
```

## Pull requests

- Fork the repo and create a branch from `main`
- Run `pnpm lint` and `pnpm test` before submitting
- Describe what the change does and why

## Reporting bugs

Open a GitHub issue with steps to reproduce, expected behavior, and actual behavior.

## Security vulnerabilities

See [SECURITY.md](./SECURITY.md) — do not open a public issue for security bugs.
